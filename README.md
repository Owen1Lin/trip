# 歐文＆溫妮專屬小空間

兩人共用的繁體中文私人旅遊規劃網站，固定規劃 **福岡＆九州，2026 年 10 月 21 日至 25 日，共五天**。以 HTML、CSS 與原生 JavaScript 製作，無需建置。

## 使用與資料範圍

所有行程瀏覽與操作必須先以已授權的 Google／Gmail 帳號登入。前端設定與隱藏畫面不能替代存取權限；真正的共享資料由 Supabase 登入、成員清單與 Row Level Security 保護。

同一瀏覽器首次登入後會保留登入狀態，重新開啟網站或新分頁時自動恢復，不需再次操作 Google 登入。重新開啟時以安全載入畫面恢復登入，不先停留登入表單；同一次恢復僅核實一組使用者與會員資料，通過後即可進入，並在背景載入共同行程。網站會更新到期憑證並自動核實會員資格；主動登出、清除網站資料或登入授權失效時才需重新登入。換裝置或換瀏覽器仍需首次登入，瀏覽器禁止長期儲存時會顯示提示。

每一天依開始時間分為上午（00:00 至 12:00 前）與下午（12:00 至 24:00 前）。列表以時間、分類、名稱及建立者同列呈現，點開可編輯、補充備註與自訂欄位，亦可完成、刪除、複製或移動活動。沒有開始時間的項目另列「時間待確認」，不推測時段；舊「中午／晚上」活動保留內容並依開始時間重新分組。活動以不同顏色與文字標示歐文／溫妮的建立及更新來源；舊版備份無署名時顯示未署名。可匯出 JSON 備份及驗證後匯入；錯誤資料不應覆蓋現有規劃。

新增行程先選分類，再填自由文字；同一批套用同一分類，可換行或以新日期分隔多筆。例如「10/21 0600-0700早餐 飯店 10.22 08-10 出門」會預覽為 10/21 06:00–07:00「早餐 飯店」及 10/22 08:00–10:00「出門」。同日可按「時間 名稱」依序填寫多筆；不同格式不明確時請改為一筆一行。

下方「預覽」逐筆保留完整原文，並可直接修改名稱、日期、開始／結束時間及備註；送出採用修正後資料。修改上方原文會重建預覽並取代手動修正，介面會明示。未寫日期時，首筆採目前選取日期，後筆沿用本批前一個明確日期；寫了不明或非法日期時則要求修正，不偷偷套用其他日期。

本機解析支援 `10月21日`、`10/21`、`10.21`、`2026-10-21`、`2026.10.21`，以及 `7-14`、`0700-1400`、`07:00-14:00`、`7點到下午2點`、常見全形符號及 AM／PM。未寫年份採旅行年份 2026，開始日期仍限 10/21～10/25。這不是全球所有格式的無歧義解析；例如 `7-11 買飲料` 保留為名稱並提示核對，無法辨識的片段保留原文，格式錯誤須修正。未填時間可留待確認。

日期／時間標頭後的下一行可作為標題，其後補充內容併入備註；遇到下一個日期／時間標頭才分成新活動。分段有歧義時要求核對。例如下列虛構資料是一筆活動：

```text
10/25 2350-0130
示範航空XY801
預定編號:DEMO42
```

結束時間早於開始時，須在預覽確認「結束於翌日」或修正時間；相同時間不會自動視為 24 小時。明寫翌日或結束日期會顯示其起訖。跨日活動以 `endDayOffset: 1` 保存，仍只列在開始日；10/25 可結束於 10/26，不新增第六天。列表有「跨日 +1」文字標籤，展開顯示完整日期及日本時間；編輯、移動、複製、備份及共享保留偏移量，舊資料未帶此欄位時視為當日結束。

一次最多 100 筆、10000 字，每天最多 100 筆；有阻擋問題時整批不加入，保留原文與預覽修正。解析在裝置本機進行，不呼叫模型。本次未新增跨平台影片、網址或圖片摘要功能；既有公開連結匯入與 Qwen／Llama 介面維持原有範圍。

行程與匯入草稿的購物清單、注意事項整合為單一「備註」，最多 5000 字；既有雙欄資料會保留原文與標頭合併，重複讀取不會重複附加。

任何行程變更後會出現固定「儲存」提醒，儲存成功才解除；儲存途中又有修改、失敗或版本衝突時，仍保留提醒。這是手動儲存，不是自動儲存。尚未按「新增」的輸入不包含在儲存內容中。

兩位授權成員使用同一份雲端行程快照。同步不是即時多人編輯，遇到其他裝置已更新時，需要先取得最新資料再處理修改。請在覆蓋或匯入前備份。

## 公開連結匯入

登入後可貼上 Google Maps、Threads 或 Instagram 連結，讀取可取得的公開標題與描述，整理成可編輯草稿。可選公開資料、Qwen 或 Llama；模型僅協助整理有來源依據的內容。來源不提供的資訊標示「待確認」，不會推測活動日期或將營業時間當成行程時間。

Google Maps 若只回傳通用頁面，可從成功解析的公開地點網址預填名稱，並明確標示名稱仍需核對。這不代表已取得或核實地址、電話、營業時間等商家資訊。

請核對草稿，選擇五天內的日期、開始與結束時間，時段依開始時間判定，勾選確認後才加入行程。來源連結保留於活動自訂欄位；加入後請按「儲存」。草稿尚未加入前只在頁面記憶體中，重新整理或登出會清除。

公開擷取需要部署 Supabase `link-import` Edge Function；Qwen／Llama 需要伺服器端模型設定。來源網站限制存取、需登入或尚未部署服務時，會明確提示並提供手動草稿；這不表示已取得公開資料。部署及限制見 [DEPLOYMENT.md](DEPLOYMENT.md)。

核實登入前不載入私人行程；登出後清除畫面、編輯表單及這個瀏覽器保存的登入憑證，其他開啟的分頁也會鎖定。登入憑證存於 `localStorage`，行程草稿仍以 `sessionStorage` 暫存在各分頁；記住登入不等於已把修改儲存到雲端。重新整理會保留有效草稿，登出清除；關閉分頁可能移除尚未同步的變更。公共裝置使用後請登出。儲存失敗時請依提示匯出備份。

## 開發與部署

iPhone 可在 Safari 開啟網站，點「分享」→「加入主畫面」，使用提供的雙人飛機插畫作為圖示。若已有舊捷徑，請先移除舊捷徑，再重新加入，以更新 iOS 快取的圖示。圖示設定不提供離線功能，也不改變登入與同步方式。

網站以手機操作為主：底部「行程／新增／匯入／共同手帳」切換主要工作，五天日期列方便換天；活動在對話框新增／編輯，備註與移動／複製可展開。設計參考、操作取捨與驗收範圍見 [DESIGN.md](DESIGN.md)。

```sh
cd /workspace/trip
python3 -m http.server 3000 --bind 0.0.0.0
```

開啟 `http://localhost:3000`。登入功能需要 Supabase、Google OAuth、兩位授權成員與允許的回呼網址設定。尚未完成設定時，不提供繞過登入的正式使用方式。部署目錄為專案根目錄，無建置指令。詳細步驟見 [DEPLOYMENT.md](DEPLOYMENT.md)。

圖片隨 repository 儲存，使用系統字體。`chatgpt.site` 網域託管尚未整合；程式推送 GitHub 不代表網站已發布至該網域。

## 審查與驗收

四位 AI 協作角色為康康（網頁工程）、小思（UI／UX）、去去（APP 與跨裝置開發）、阿福（獨立驗收），分工與流程見 [TEAM.md](TEAM.md)。測試環境需提供 Node.js 24、Playwright 及 Chromium，啟動上述靜態服務後執行：

```sh
node tests/planner.test.cjs
node tests/cloud.test.cjs
node tests/link-import.test.cjs
node tests/mobile-flow.test.cjs
node tests/auth-session.test.cjs
node tests/quick-entry.test.cjs
node tests/flexible-parser.test.cjs
node tests/flexible-flow.test.cjs
```

可用 `TEST_URL` 指定服務網址、`CHROMIUM_PATH` 指定 Chromium 路徑。瀏覽器測試使用模擬登入及 API；它不能證明真實 Google 登入、Supabase 成員權限、兩人共享或正式部署已驗證。正式驗收需以兩個授權 Gmail 帳號與一個非成員帳號實際測試。

GitHub 同步是在已授權的工作階段提交並推送驗收後的變更，不是離開工作階段後仍會運作的常駐服務。
